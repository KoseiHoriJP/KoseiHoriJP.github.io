Academic Projects

Name Pronunciation to Katakana Conversion System

Developed a pronunciation-based system to convert English and French personal names into Japanese Katakana using natural language processing and machine learning. Collected and processed approximately 6,960 names with IPA (International Phonetic Alphabet) and pronunciation information. Combined rule-based phonetic conversion with a Seq2Seq neural network using GRU and attention mechanisms, and conducted error analysis to identify pronunciation patterns requiring improvement.

Technologies: Python, NLP, IPA, Seq2Seq, GRU, Attention Mechanism

Influyan – Interactive Influenza Map

Developed an interactive application to visualize and analyze influenza infection trends across Japan's Kansai region. Created geographic visualizations and historical data graphs to illustrate regional infection patterns, along with forecasting visualizations to communicate potential future trends. The system was designed around public health data from Japanese authorities, incorporating geospatial analysis and time-series forecasting concepts.

Focus: Data Visualization, Geospatial Analysis, Time-Series Forecasting

Rinder – ResearchMatch Web Application

Developed a full-stack web application connecting university researchers with potential research participants. Contributed to frontend development using React and JavaScript, supporting research project discovery, survey participation, and user interactions. Worked within a three-tier architecture integrating a React frontend, Flask REST APIs, and a MySQL database. The team successfully completed nine core system test cases.

Technologies: React, JavaScript, Python (Flask), MySQL, REST APIs, Axios

Rugby Scrum Analysis with Machine Learning

October 2026 – Present

Exploring machine learning methods for analyzing rugby scrums using posture and movement features from video to estimate scrum stability and force direction. The research aims to help reduce injury risk, identify technical weaknesses, and provide objective support for referees' penalty decisions.

GDMC 2027 – Settlement Generation in Minecraft

October 2026 – Present

Developing algorithms for GDMC 2027, an international competition for generating settlements in Minecraft. Inspired by how real cities form, the project aims to create natural, functional settlements that adapt to rivers and terrain. The planned approach analyzes elevation, slopes, and water sources to identify suitable residential and farming areas, then combines road network generation with building placement.
